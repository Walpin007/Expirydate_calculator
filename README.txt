TIME LIMIT PWA v0.1.5

배포
1. ZIP을 풀고 index.html, pwa.js, sw.js, manifest.webmanifest, icons 폴더를
   현재 계산기 GitHub Pages의 index.html이 있는 위치에 함께 올립니다.
   icons 폴더 구조를 그대로 유지하세요. ZIP 자체를 올리는 것이 아닙니다.
2. GitHub Pages 배포 완료 후 HTTPS 주소를 Safari에서 엽니다.
3. 화면 하단 버전 v0.1.5와 '오프라인 계산 준비 완료'를 확인합니다.
4. 공유 → 홈 화면에 추가 → 웹 앱으로 열기를 켜고 추가합니다.
5. 홈 화면 아이콘으로 실행하여 비행기 모드에서도 수동 계산이 되는지 확인합니다.

포함 파일
index.html: 계산기 (기존 날짜·시간 표시 및 음성 기능 유지)
manifest.webmanifest: 앱 이름, 홈 화면 실행 설정, 아이콘
pwa.js: 서비스 워커 등록 및 업데이트 버튼
sw.js: 온라인 최신 파일 우선 확인 및 오프라인 파일 제공
icons/: 192px, 512px, 마스크용 512px, Apple 홈 화면용 180px 아이콘

주의
- 처음 한 번은 인터넷에 연결해 오프라인 파일 준비를 완료해야 합니다.
- 음성 인식은 인터넷 및 브라우저 지원에 따라 달라집니다.
  홈 화면에서 마이크가 동작하지 않으면 수동 입력을 사용하거나 Safari에서 엽니다.
- iOS가 사이트 저장 공간을 정리한 경우 온라인에서 다시 열어야 합니다.
- 파일 앱에서 index.html을 직접 열면 PWA 설치/서비스 워커가 동작하지 않습니다.
- 기존 홈 화면 아이콘 이미지가 그대로면 기존 아이콘을 삭제하고 다시 추가하세요.
- 앱스토어용 IPA/APK가 아니라 GitHub Pages 등 HTTPS에서 배포하는 PWA입니다.

업데이트
- 이 파일 세트를 함께 업로드합니다. index.html만 교체하지 마세요.
- 향후 수정 시 index.html과 sw.js의 버전을 함께 올립니다.
- 온라인에서는 최신 파일을 우선 확인하고, 연결 실패 시 저장된 파일을 사용합니다.
- '새 버전 적용' 버튼은 현재 입력을 확인한 뒤 누르세요. 적용 시 화면이 다시 열립니다.
- 캐시는 이 계산기의 배포 경로별로 구분하며 다른 사이트의 캐시는 지우지 않습니다.

확인된 범위
코드 및 서비스 워커 모의 검증. 실제 iPhone 홈 화면의 마이크와 설치 동작은
기기에서 확인이 필요합니다.
