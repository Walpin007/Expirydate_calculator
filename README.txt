TIME LIMIT PWA v0.1.10

배포
1. ZIP을 풀고 index.html, pwa.js, sw.js, manifest.webmanifest, icons 폴더를
   현재 계산기 GitHub Pages의 index.html이 있는 위치에 함께 올립니다.
   icons 폴더 구조를 그대로 유지하세요. ZIP 자체를 올리는 것이 아닙니다.
2. GitHub Pages 배포 완료 후 HTTPS 주소를 Safari에서 엽니다.
3. 화면 하단 버전 v0.1.10과 '오프라인 계산 준비 완료'를 확인합니다.
4. 공유 → 홈 화면에 추가 → 웹 앱으로 열기를 켜고 추가합니다.
5. 홈 화면 아이콘으로 실행하여 비행기 모드에서도 수동 계산이 되는지 확인합니다.

포함 파일
index.html: 계산기 (기존 날짜·시간 표시 및 음성 기능 유지)
manifest.webmanifest: 앱 이름, 홈 화면 실행 설정, 아이콘
pwa.js: 서비스 워커 등록 및 업데이트 버튼
sw.js: 온라인 최신 파일 우선 확인 및 오프라인 파일 제공
icons/: 192px, 512px, 마스크용 512px, Apple 홈 화면용 180px 아이콘

주의
- 처음 한 번은 인터넷에 연결해 오프라인 파일 준비를 완료해야 합니다.
- 음성 인식은 인터넷 및 브라우저 지원에 따라 달라집니다.
  홈 화면에서 마이크가 동작하지 않으면 수동 입력을 사용하거나 Safari에서 엽니다.
- iOS가 사이트 저장 공간을 정리한 경우 온라인에서 다시 열어야 합니다.
- '날짜 차이'는 기준 일시와 종료 일시를 비교해 총 경과시간을 hhmm 형식으로 표시합니다.
  예: 27SEP2026 1530 → 28SEP2026 1815 = 2645 (26시간 45분).
- 파일 앱에서 index.html을 직접 열면 PWA 설치/서비스 워커가 동작하지 않습니다.
- 기존 홈 화면 아이콘 이미지가 그대로면 기존 아이콘을 삭제하고 다시 추가하세요.
- 앱스토어용 IPA/APK가 아니라 GitHub Pages 등 HTTPS에서 배포하는 PWA입니다.

업데이트
- 이 파일 세트를 함께 업로드합니다. index.html만 교체하지 마세요.
- 향후 수정 시 index.html과 sw.js의 버전을 함께 올립니다.
- 온라인에서는 최신 파일을 우선 확인하고, 연결 실패 시 저장된 파일을 사용합니다.
- '새 버전 적용' 버튼은 현재 입력을 확인한 뒤 누르세요. 적용 시 화면이 다시 열립니다.
- 캐시는 이 계산기의 배포 경로별로 구분하며 다른 사이트의 캐시는 지우지 않습니다.

확인된 범위
코드 및 서비스 워커 모의 검증. 실제 iPhone 홈 화면의 마이크와 설치 동작은
기기에서 확인이 필요합니다.

v0.1.10 — 계산 과정 표시
- 음성/수동 결과 아래에 실제 계산 과정을 항상 펼쳐 보여줍니다.
- 더하기는 다음 자정까지, 24시간 단위의 날짜, 남은 시간·분 순서로 나눕니다.
- 빼기는 같은 날 자정까지, 24시간 단위의 날짜, 남은 시간·분을 거꾸로 적용합니다.
- 각 단계에 중간 일시와 남은 기간을 표시합니다. 날짜는 DDMMMYYYY, 시각은 24시간제 HHMM입니다.
- 날짜 차이는 구간별 경과시간을 합한 뒤 HHMM으로 표시하는 과정을 보여줍니다.
- 음성의 제한시간 비교도 제한−경과(잔여) 또는 경과−제한(초과)을 함께 표시합니다.
- 예: 14NOV2026 1010 + 38시간 40분
  1) 다음 자정까지 13시간 50분 → 15NOV2026 0000, 남은 24시간 50분
  2) 24시간(1일) → 16NOV2026 0000, 남은 50분
  3) 50분 → 16NOV2026 0050
- 긴 기간의 온전한 날짜는 한 단계로 묶어 화면을 길게 늘이지 않습니다.
- 결과 복사와 결과로 추가 계산은 최종 값으로 동작합니다.

v0.1.9 — 음성 해석 및 입력 편의 개선 (2026-11-14)
- 음성의 빼기·전, 더하기·후·뒤를 구분합니다. “오늘 15시에서 두 시간 빼기” = 1300.
- “오늘 오후 세 시 반부터 두 시간” = 1730. “두 시간 반”, “반 시간”도 지원합니다.
- 어제·오늘·내일·모레·지금은 한국 시간 기준입니다. 지금은 인식 문장 처리 시각의 분 단위입니다.
- 한/두/세/열한/스물두 등의 수사와 숫자로 읽는 년·월·일 표현을 지원합니다.
- 해석되지 않은 표현이나 더하기·빼기 혼용은 계산하지 않고 수정 안내를 표시합니다.
- “오늘 15시”, “내일”처럼 미완성인 입력도 인식한 날짜·시각을 수동 입력칸에 먼저 채웁니다.
- 기준 날짜와 종료 날짜에 오늘/달력 선택을 추가했습니다. 표시 형식은 DDMMMYYYY입니다.
- 날짜 차이의 종료 날짜·시각을 분리하고 시각은 숫자 키패드로 입력합니다. 결과는 총 시간의 HHMM입니다.
- 음성/수동 결과를 복사할 수 있습니다. 자동 복사가 차단되면 선택 가능한 텍스트를 제공합니다.
- 날짜·시각 계산 결과는 “결과로 추가 계산”으로 다음 계산의 기준 일시에 넣을 수 있습니다.
  경과시간(HHMM)은 복사만 제공합니다. 날짜가 없는 기간을 기준 일시로 사용하지 않습니다.
- 새 버전 적용 전에 입력을 세션에 보관하고 재시작 후 한 번 복원합니다(30분 이내).
  “지금”도 업데이트 전 해석된 시각을 유지합니다. 일반적인 새 실행은 오늘 날짜/빈 시각으로 시작합니다.
- 입력 복원은 v0.1.9 실행 중 이루어지는 이후 업데이트부터 적용됩니다.
  v0.1.8 화면에서 처음 v0.1.9로 전환할 때는 기존 코드에 저장 기능이 없으므로 입력 복원이 불가능합니다.
- 입력 보존이 차단된 환경에서는 자동 재시작을 멈추고 복사 안내를 표시합니다.
- 자동 검증: 163개 테스트를 서울/UTC/뉴욕에서 각각 실행하여 총 489건 통과.
  계산, 자연어, 부분 입력, 날짜 선택, 복사, 연속 계산,
  업데이트 복원, 오프라인 캐시를 확인합니다. 실제 iPhone의 마이크와 달력 UI는 기기 확인이 필요합니다.
- 브라우저 검증: 수동 계산, 종료 일시 분리, 결과 복사, 추가 계산, 서비스 워커 교체 후 입력 복원 확인.

v0.1.8 — 음성 날짜 '오늘'
- "오늘 15시부터 40시간"처럼 말하면 한국 시간의 오늘 날짜로 계산하고 수동 입력칸에도 채웁니다.
- "오늘"만 말하면 오늘 날짜를 채우고 시각과 계산할 기간의 입력을 안내합니다.
- 날짜 기준은 한국 시간(UTC+9)이며 자정을 지나면 새 날짜를 사용합니다.



v0.1.7 — HHMM 기간 및 회귀 테스트 (2026-11-08)
기준: Walpin007/Expirydate_calculator
커밋: cad5bf4d34e9bb110fd1fea4f9d9f2c44abc63a7
HHMM 기간 입력과 날짜 계산 회귀 테스트를 추가한 버전입니다.

HHMM 기간 입력
- 수동 계산의 [HHMM · 시간/분] 버튼을 선택하고 기간을 입력합니다.
- 0130 = 1시간 30분, 2645 = 26시간 45분, 10000 = 100시간.
- 4자리 이상 숫자로 입력하며 마지막 두 자리는 분(00~59)입니다.
- 0001부터 8760000(87,600시간 = 3,650일)까지 지원합니다.
- 0000, 0060, 130, 01:30, 음수, 소수는 오류로 안내합니다.
- 더하기/빼기는 + / − 버튼으로 선택합니다.
- 기간 단위를 바꿀 때 숫자 자체는 자동 환산하지 않습니다. 선택한 단위와 입력을 확인하세요.
- 기준 시각의 기존 HHMM은 0000~2359이며, 기간 HHMM과 구분됩니다.
- 음성 문장의 기간은 기존처럼 '1시간 30분' 형태를 사용합니다.

자동 테스트 실행 (Node.js 20 이상, 별도 패키지 설치 불필요)
1. 이 폴더를 터미널 또는 명령 프롬프트에서 엽니다.
2. npm test
   서울 / UTC / 뉴욕 시간대에서 동일한 테스트를 각각 실행합니다.
3. 현재 시간대에서 한 번만 실행: npm run test:single
성공 시 종료 코드 0, 실패 시 종료 코드 1입니다.
Windows에서도 npm test 명령은 동일합니다.

테스트 구조
- test/harness.cjs: index.html의 실제 인라인 스크립트를 읽어 메모리에서만
  테스트용 함수를 노출합니다. 운영 파일에 테스트 전용 전역 객체를 추가하지 않습니다.
- test/calculator.test.cjs: 계산/날짜/HHMM/음성 문자열/수동 UI 이벤트 검증.
- test/pwa.test.cjs: 서비스 워커와 PWA 등록 코드를 모의 환경에서 실행합니다.
- test/run-timezones.cjs: 독립 Node 프로세스를 각 시간대로 실행합니다.
- test 파일 및 package.json은 브라우저에서 로드하거나 오프라인 캐시에 넣지 않습니다.

입력 검증 보완
- '1.5시간'을 5시간, '-1시간'을 1시간으로 해석하던 부분을 오류로 처리합니다.
- '15시 100분'을 15시 10분으로 잘라 해석하지 않도록 합니다.
- 날짜 생성 함수의 모든 구성값은 유한한 정수인지 확인합니다.

기존 정책 유지
- 기준 날짜 입력은 1900~2100년입니다.
- 최대 '10년'은 달력의 10주년이 아니라 5,256,000분 = 3,650일입니다.
- 날짜 차이 모드에는 10년 제한이 없습니다. 두 입력 날짜의 유효 범위만 적용합니다.
- 연도/월을 생략한 음성 입력은 한국 시간의 현재 연월 또는 앞 날짜를 사용합니다.
- 한글 수사 자체('두 시간', '이십칠일')를 숫자로 변환하는 기능은 추가하지 않았습니다.
  음성 인식 결과가 '2시간', '27일' 등으로 전달되는 기존 입력 범위를 검증합니다.

수동 적용
- 동봉된 전체 앱 파일을 기존 파일과 비교한 뒤 적용합니다.
- 실제 런타임 변경은 index.html과 sw.js입니다. 두 파일은 함께 적용해야 합니다.
- pwa.js, manifest.webmanifest, icons는 기준 커밋 그대로입니다.
- sw.js는 버전만 v0.1.7로 올렸고 기존 캐시/업데이트/오프라인 전략을 유지합니다.
- 별도 빌드 과정이나 서버 API를 추가하지 않았습니다.
- 자동 테스트는 브라우저/실기기 검증을 대신하지 않습니다. 상세 결과와 기기 점검 항목은
  아래 실기기 확인 항목을 확인하세요.

자동 검증 결과
- Node.js v24.22.1에서 134개 테스트를 서울/UTC/뉴욕 각각 실행: 총 402건 통과.
- 실제 iPhone에서는 마이크 허용/거부, 홈 화면 설치, HHMM 선행 0 입력,
  온라인 준비 후 비행기 모드 재실행, 기존 버전에서 새 버전 적용을 확인하세요.
